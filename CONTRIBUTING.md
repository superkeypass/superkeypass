# Contributing to SuperkeyPass

Thanks for being here. The project is in **early design**, so the most useful
contributions right now are ideas, critique, and threat-model holes — not code.

## Ways to help

- **Poke holes in the design.** Read [`docs/`](docs/) and open an issue, or a
  PR against the doc, when something is wrong, missing, or naive.
- **Security issues** go through [SECURITY.md](SECURITY.md), never a public
  issue.
- **Feature ideas** — use the feature-request template. Say who it helps
  (remember the target user: a 70-year-old set up by a relative).

## Pull requests

- Branch from `main`; `main` is protected and needs one approving review.
- Keep PRs focused — one change, one reason.
- Fill in the PR template, including the security-impact line.
- Decisions with long-lived consequences get an ADR in `docs/adr/`.
