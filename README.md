# SuperkeyPass

**A family password vault with nothing to remember.**

SuperkeyPass is an open-source, self-hostable password manager built for
families — especially the parents and grandparents who get set up by the one
tech-savvy relative and should never have to recall a master password. You
unlock with what you already carry: Face ID, Touch ID, Windows Hello, or a
fingerprint security key. If everything is lost, a printed recovery sheet and
an admin-assisted recovery flow get you back in. And if a device is ever
grabbed and dumped, tamper alerts fire to trusted family members and an
exposure report tells you exactly which passwords to rotate first.

> **Status: early design.** There is no working software yet. The design
> lives in [`docs/`](docs/) — start with [the vision](docs/vision.md) and
> [the threat model](docs/threat-model.md).
